## Why this step matters

An EEGLAB dataset has two parts: the description (channel names and positions, events, sampling rate, processing history) and the signal itself (the numbers in `EEG.data`).

In EEGLAB 2026.1, saving writes the two parts to two files with the same name by default: a `.set` file with the description and a `.fdt` file with the signal. The sample `eeglab_data.set` that ships with EEGLAB is saved the same way. You can also ask for one file that holds both parts.

A `.set` without its `.fdt` has no signal. If you copy or send the `.set` file alone, the person who tries to open it gets an error. This lesson shows how to tell the two cases apart and how to keep the two files together.

## Steps in the GUI

### 1. See the two files of the sample

1. Open the `sample_data` folder inside your EEGLAB folder, in File Explorer on Windows or Finder on macOS.
2. You will find `eeglab_data.set` (about 0.35 MB) and `eeglab_data.fdt` (about 3.9 MB). The `.fdt` is the larger one because it holds the signal: 32 channels × 30504 samples × 4 bytes per number.

### 2. Save a copy in your folder

1. With `eeglab_data.set` open in EEGLAB, open <MenuPath>File > Save current dataset as</MenuPath>.
2. Go to your own lessons folder, not `sample_data`, and type the name `D1_copy.set`.
3. Click <UiLabel>Save</UiLabel>.
4. Look in your folder: there are two files, `D1_copy.set` (about 0.35 MB) and `D1_copy.fdt` (about 3.9 MB). You typed one name, and EEGLAB wrote both files.

### 3. Find the saving option

1. Open <MenuPath>File > Preferences</MenuPath>.
2. In the first group of options, find the checkbox that starts with <UiLabel>If set, save not one but two files for each dataset (header and data).</UiLabel>
3. Close the window with <UiLabel>Cancel</UiLabel>, and do not click <UiLabel>OK</UiLabel>. In this course we keep the default: two files.

You may find the checkbox unticked, even though EEGLAB just saved two files. The window reads its value from one settings file, while saving follows another one, until you click <UiLabel>OK</UiLabel> in this window for the first time. After that, saving follows the checkbox.

## The equivalent script

```matlab
% Start EEGLAB and load the sample dataset
[ALLEEG, EEG, CURRENTSET, ALLCOM] = eeglab;
sampleFolder = fullfile(fileparts(which('eeglab')), 'sample_data');
EEG = pop_loadset('filename', 'eeglab_data.set', 'filepath', sampleFolder);

% The sample keeps its signal in a separate file
EEG.datfile                                 % 'eeglab_data.fdt'
dir(fullfile(sampleFolder, 'eeglab_data.*'))   % the .fdt and the .set

% Save a copy in your own folder: two files by default in EEGLAB 2026.1
myFolder = 'C:\Users\me\Documents\eeg-course';   % change it
EEG = pop_saveset(EEG, 'filename', 'D1_copy.set', 'filepath', myFolder);
dir(fullfile(myFolder, 'D1_copy.*'))           % D1_copy.fdt and D1_copy.set

% Ask for one file explicitly, if you need it
EEG = pop_saveset(EEG, 'filename', 'D1_onefile.set', 'filepath', myFolder, ...
    'savemode', 'onefile');
dir(fullfile(myFolder, 'D1_onefile.*'))        % D1_onefile.set only, about 4 MB
```

- `EEG.datfile` holds the name of the `.fdt` file. When it is empty, the signal is inside the `.set` file.
- `'savemode', 'onefile'` forces one file for this save only, whatever the preference says. `'savemode', 'twofiles'` forces two files.

## Which value should I choose?

| Choice | When | What you get |
|---|---|---|
| Two files (the default in 2026.1) | Almost always, and with a STUDY in station 8, because EEGLAB reads the description alone quickly. | `name.set` and `name.fdt`, always together |
| One file (untick the option in <MenuPath>File > Preferences</MenuPath> and click <UiLabel>OK</UiLabel>, or `'savemode', 'onefile'`) | You want to email one dataset or copy it without forgetting a file. | `name.set` only |

**Resaving keeps the format on disk.** <MenuPath>File > Resave current dataset(s)</MenuPath> on a two-file dataset writes two files again, even if your preference is one file. In that case the Command Window prints a note starting with `Note that your memory options for saving datasets does not correspond`. This is normal.

<Callout type="note" title="Two files, not one">
Some pages of the EEGLAB documentation say that EEGLAB saves one file by default since 2021, and the <MenuPath>File > Preferences</MenuPath> window says so too. But the settings file that ships with EEGLAB 2026.1 turns the two-file option on, so saving writes two files. Trust what you see in your folder.
</Callout>

## Common mistakes

- **Copying or emailing the `.set` file alone.** Always move both files, with the same name, into the same folder.
- **Renaming one of the two files in the file explorer.** The `.set` file remembers the name of its `.fdt`. To rename a dataset, open it in EEGLAB and use <MenuPath>File > Save current dataset as</MenuPath> with the new name.
- **Opening the `.fdt` file.** Always open the `.set`. EEGLAB reads the `.fdt` with it.
- **An error that starts with `file` and ends with `you must also rename/move the associated data file.`** The `.fdt` file is not next to the `.set` file, so the dataset does not open. Find it and put it in the same folder. The sample `eeglab_data.set` is an exception: EEGLAB puts the `sample_data` folder on the MATLAB path, so MATLAB finds `eeglab_data.fdt` there even if you copy the `.set` alone. Your own files are not treated this way.
- **Clicking <UiLabel>OK</UiLabel> in <MenuPath>File > Preferences</MenuPath> by accident.** If the two-files checkbox is unticked, saving then writes one file. That is fine, but do not be surprised when your files change.
- **Being surprised that the old `.fdt` disappeared.** If you save a two-file dataset as one file with the same name in the same folder, EEGLAB deletes the old `.fdt`, because the signal is now inside the `.set` file. It prints `Old .fdt file detected on disk, deleting file since the Matlab file now contains all the data`. This is why you save your copies in your own folder, never over the sample.

## How to check it worked

1. `sample_data` has `eeglab_data.set` and `eeglab_data.fdt`, and `EEG.datfile` gives `'eeglab_data.fdt'` after loading the sample.
2. Your folder has `D1_copy.set` (about 0.35 MB) and `D1_copy.fdt` (about 3.9 MB).
3. If you ran the script: `D1_onefile.set` alone, about 4 MB.
4. `D1_copy.set` opens with <MenuPath>File > Load existing dataset</MenuPath> and shows 32 channels and 154 events.

You can delete `D1_copy.*` and `D1_onefile.set` after the lesson. The next lessons do not use them.
