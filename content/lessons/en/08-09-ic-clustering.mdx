## Why this step matters

Channel Pz in one person and Pz in another do not record the same brain sources. The skull, the folding of the cortex and the reference all differ. ICA offers another route: each component is one source estimated from the data of one participant. But components have no shared names across people. Component 5 in one participant has nothing to do with component 5 in another.

Clustering solves this. It groups components from different participants that look like the same source: similar scalp maps and nearby dipoles. Each cluster can then be treated like a "virtual channel" in the group plots and statistics.

Clustering has no single correct answer. Change the measures or the number of clusters, and the clusters change. So this lesson teaches you to build clusters, and also to judge them before you trust them.

## Steps in the GUI

**About the data (D6):** `animal_mine.study` with its designs and channel measures. Clustering needs ICA, ICLabel and a dipole for each component in every file. The ready files already hold the authors' ICA (31 components per participant, 29 for `cba`), so we do not compute it again. They also hold a dipole for each component, fitted by the authors with the spherical BESA head model (`standard_BESA.mat`, which comes with the dipfit plugin), so we keep them too. There are no ICLabel results, so the "Starting point" script runs ICLabel. It fits dipoles only if they are missing or their head model file cannot be found.

<Callout type="warning">
**Before you start: what the starting point does, and one requirement.**

- **Fieldtrip-lite must be installed**, because keeping only in-brain dipoles uses it, and so would dipole fitting (see the statistics lesson for how to check and install it). If dipoles must be fitted, the script stops with `Install Fieldtrip-lite first` when it is missing.
- **The starting point runs ICLabel for every participant**: a few minutes for the 14 participants. {/* ICLabel time: measured in the combined run */} If the dipoles were missing, it would also fit them, which takes about 25 minutes. The script prints each participant as it finishes, and the total time at the end. Run it once: the results are saved in the dataset files, and the next run skips this step.
- **The ICA is not computed again.** It comes with the data, so your components are the same as in the lesson images. In your own data, run ICA on the continuous data with a 1 Hz high-pass copy, as in station 4.
</Callout>

**1. Run the starting point and check the result**

1. Run the "Starting point" script, and wait for it to finish.
2. Both files of a participant should hold **the same ICA**. EEGLAB recognizes them as one decomposition only if their weights are identical. The script checks this: when the weights match, it fits the dipoles once and copies them to the second file, and otherwise it fits each file.

**2. Choose the components to cluster**

1. Open <MenuPath>Study > Edit study info</MenuPath>. The <UiLabel>Create a new STUDY set -- pop_study()</UiLabel> window opens (it has this title for editing too).
2. Press <UiLabel>Select by r.v.</UiLabel>. In the small window keep `15` as the maximum residual variance, and keep <UiLabel>Keep only in-brain dipoles (requires Fieldtrip extension).</UiLabel> ticked. Press <UiLabel>Ok</UiLabel>.
3. The component column for each dataset now lists fewer components: only those whose dipole explains their scalp map with less than 15% residual variance. Press <UiLabel>Ok</UiLabel>. Changing the component selection also deletes any earlier clusters, so you start clean. The script does the same with `STUDY.cluster = []`.

**3. Precompute component measures**

1. Open <MenuPath>Study > Precompute component measures</MenuPath>.
2. Keep <UiLabel>Compute ERP/spectrum/ERSP only for components selected by RV (set) or for all components (unset)</UiLabel> ticked.
3. Tick <UiLabel>Scalp maps</UiLabel>, <UiLabel>Power spectrum</UiLabel> and <UiLabel>ERPs</UiLabel>. Press <UiLabel>Ok</UiLabel>. EEGLAB writes component files next to each dataset.

**4. Build the preclustering array**

1. In <MenuPath>Study > Select/Edit study design(s)</MenuPath> make `image only` the current design. EEGLAB clusters only with a design that holds every dataset. Designs 2 and 3 both do; we use `image only` because clustering ignores the groups.
2. Open <MenuPath>Study > PCA clustering (original) > Build preclustering array</MenuPath>. The <UiLabel>Select and compute component measures for later clustering -- pop_preclust()</UiLabel> window opens.
3. In the location-based part of the window, tick `dipole locations` and type `10` in its weight box.
4. Tick `scalp maps`, keep `3` in its PCA box and `1` as its weight, keep <UiLabel>Use channel values</UiLabel>, and keep <UiLabel>Absolute values</UiLabel> ticked.
5. Leave every line of the time-based part (`spectra`, `ERPs`, `ERSPs`, `ITCs`) unticked. Press <UiLabel>Ok</UiLabel>.

The window itself warns: <UiLabel>Mixing time-based and location-based measures might result in statistical double-dipping</UiLabel>. If you cluster on ERPs and then test the ERPs of the clusters, the clusters were partly built from the effect you test. Clustering on location only avoids this.

**5. Cluster**

1. Open <MenuPath>Study > PCA clustering (original) > Cluster components</MenuPath>. The <UiLabel>Set clustering algorithm -- pop_clust()</UiLabel> window opens.
2. In <UiLabel>Clustering algorithm:</UiLabel> choose <UiLabel>Kmeans (stat. toolbox)</UiLabel>. Without the Statistics and Machine Learning Toolbox, choose <UiLabel>Kmeanscluster (no toolbox)</UiLabel>.
3. Keep the value EEGLAB proposes in <UiLabel>Number of clusters to compute:</UiLabel>. It equals the average number of selected components per dataset, so each cluster holds about one component per participant on average.
4. Tick <UiLabel>Separate outliers (enter std.)</UiLabel> and keep `3`. Press <UiLabel>Ok</UiLabel>.

**6. Look at the clusters and judge them**

1. Open <MenuPath>Study > Edit/plot component clusters</MenuPath>. The <UiLabel>View and edit current component clusters -- pop_clustedit()</UiLabel> window opens. The left list shows each cluster with its number of components, for example `Cls 3 (12 ICs)`.
2. Choose a cluster, then press <UiLabel>Plot scalp maps</UiLabel> on the left: the mean map of the cluster. In the right list choose all its components, then <UiLabel>Plot scalp map(s)</UiLabel>: one map per member.
3. Press <UiLabel>Plot dipoles</UiLabel>: the member dipoles in blue and their mean in red.
4. Judge the cluster with four questions:
   - Do the member maps look alike, or is one clearly different?
   - Are the dipoles close together, or spread across the head?
   - How many **different participants** does it hold? A cluster from 4 of 14 people says little about the group.
   - Does ICLabel mostly call its members "Brain"? The script prints the median brain probability for each cluster.
5. If one member is clearly different, choose it and press <UiLabel>Remove selected outlier comps.</UiLabel>. Press <UiLabel>Ok</UiLabel> to keep your changes, then save with <MenuPath>File > Save current study</MenuPath>.

## The matching script

```matlab
% STUDY and ALLEEG come from the starting point script (ICA, dipoles and ICLabel present)
STUDY = std_selectdesign(STUDY, ALLEEG, 3);   % a design that holds every dataset

% 0. Remove earlier clusters, so new clusters do not mix with old ones
STUDY.cluster = [];
STUDY = std_checkset(STUDY, ALLEEG);   % recreates the parent cluster only

% 1. Keep components whose dipole explains the map well (residual variance below 15%)
[STUDY, ALLEEG] = std_editset(STUDY, ALLEEG, 'commands', {'inbrain', 'on', 'dipselect', 0.15});
nComps = cellfun(@numel, {STUDY.datasetinfo.comps});
fprintf('Components kept per dataset: median %g, range %d to %d\n', median(nComps), min(nComps), max(nComps));

% 2. Component measures: scalp maps for clustering, spectra and ERPs for reading the clusters
baseline = [round(ALLEEG(1).xmin*1000) 0];
[STUDY, ALLEEG] = std_precomp(STUDY, ALLEEG, 'components', 'savetrials', 'on', 'recompute', 'on', ...
    'scalp', 'on', 'spec', 'on', 'specparams', {'specmode', 'fft', 'logtrials', 'off'}, ...
    'erp', 'on', 'erpparams', {'rmbase', baseline});

% 3. Preclustering on location only: dipole positions (weight 10) and scalp maps (3 PCA dimensions)
[STUDY, ALLEEG] = std_preclust(STUDY, ALLEEG, 1, {'dipoles', 'weight', 10}, ...
    {'scalp', 'npca', 3, 'weight', 1, 'abso', 1});

% 4. k-means with outliers; fixed seed so the clusters are the same on every run
rng(1);
if exist('kmeans', 'file'), alg = 'kmeans'; else, alg = 'kmeanscluster'; end
nClust = ceil(mean(nComps));
STUDY = pop_clust(STUDY, ALLEEG, 'algorithm', alg, 'clus_num', nClust, 'outliers', 3);

% 5. Size, participants and ICLabel brain probability of each cluster
best = 0; bestN = 0;
for c = 2:numel(STUDY.cluster)
    cl = STUDY.cluster(c);
    if strncmpi(cl.name, 'outlier', 7) || isempty(cl.comps), continue; end
    sets = cl.sets(1, :);
    brain = zeros(1, numel(sets));
    for m = 1:numel(sets)
        brain(m) = ALLEEG(sets(m)).etc.ic_classification.ICLabel.classifications(cl.comps(m), 1);
    end
    nSubj = numel(unique({STUDY.datasetinfo(sets).subject}));
    fprintf('%-10s %3d ICs from %2d participants, median brain probability %.2f\n', ...
        cl.name, numel(cl.comps), nSubj, median(brain));
    if nSubj > bestN, best = c; bestN = nSubj; end
end

% 6. Maps and dipoles of the cluster with the most participants, then save
STUDY = std_topoplot(STUDY, ALLEEG, 'clusters', best, 'mode', 'apart');
STUDY = std_dipplot(STUDY, ALLEEG, 'clusters', best);
STUDY = pop_savestudy(STUDY, ALLEEG, 'savemode', 'resave');
```

## Which value should I choose?

| Option | In this lesson | When to change it |
|---|---|---|
| Residual variance limit | 15% | The EEGLAB default. Lower (for example 10%) keeps fewer but cleaner components. |
| Measures for clustering | Dipole locations (weight 10) and scalp maps | Add spectra when you want clusters by rhythm (for example alpha), and accept the double-dipping risk for tests on spectra. |
| Number of clusters | Average number of selected components per dataset | More clusters give smaller, tighter groups with fewer participants each. |
| Algorithm | k-means with outliers at 3 standard deviations | <UiLabel>Affinity Propagation</UiLabel> chooses the number by itself, but in this version it needs the LIMO plugin. |
| Seed | `rng(1)` in the script | k-means starts at random, so without a fixed seed the clusters change a little each run. |
| ICA seed | `'rndreset', 'no'` when you run ICA yourself | Here ICA comes with the data. In your own data, without it runica starts from a random point set by the clock. Keep it `'no'` whenever you want a repeatable result. |

## Common mistakes

- **One ICA per file instead of per participant.** EEGLAB then sees two unrelated decompositions for the same person, and the two conditions of a cluster no longer contain the same components.
- **Trusting the cluster number.** `Cls 3` in your run is not `Cls 3` in another run or another person's analysis. Name a cluster by its location and map, for example "medial parietal".
- **A cluster from few participants.** The tutorial warns that several components from the same participant in one cluster change the question from people to components. Look at the number of participants, not only the number of ICs.
- **Clustering on the measure you then test.** This is double-dipping: the clusters were partly built from the effect.
- **ICA without `'rndreset', 'no'`** in your own data. runica then starts from a different random point, so the components, and then the clusters, change on every run, even with `rng(1)` before k-means.
- **Clustering on top of old clusters.** The ready `animal.study` holds nine clusters from the authors (`Cls 2` to `Cls 9` under the parent cluster), and every new run of `pop_clust` adds clusters to the list. Delete the earlier clusters first, as the script does, and work on `animal_mine.study`.
- **Forgetting to save.** Clusters live in the STUDY. Without saving, they are lost when you close EEGLAB.

## How do you know it worked?

- **The script prints** `Components kept per dataset:` with a median and a range, and each dataset keeps at least a few components.
- **The script prints** one line per cluster with its number of ICs, its number of participants and its median brain probability.
- **The cluster editor** lists the clusters with their number of ICs, and an `outlier` cluster if outliers were found.
- **For the cluster with the most participants,** the member maps look alike and the dipoles are grouped in one area of the head.
