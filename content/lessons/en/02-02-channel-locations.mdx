## The idea

Right now your dataset knows the channel names only. It does not know where each electrode sits on the head.

Any scalp map, any step that uses neighboring channels (such as interpolating a bad channel), and ICA component maps all need these positions.

So how do you give each channel in your file its correct place on the head?

## What changes after the lookup?

In the main window, the Channel locations line turns from `No (labels only)` to `Yes`. In the electrode plot, each name appears in its place on the head.

## Why can EEGLAB not find the positions for this file?

EEGLAB finds the positions by matching each channel name with a template file of standard names, such as `FC5` or `Cz`. The match works only if the names are written the standard way.

In `S001R03.edf` the names end with extra dots: `Fc5.`, `Cz..`, `T10.`. The dots pad every name to four characters. A name such as `Cz..` does not match `Cz` in the template, so EEGLAB finds no position for it. This is a real problem you will meet with files from other systems, so we fix it here first.

**Upper or lower case does not matter.** EEGLAB compares names in lower case, so `Fc5` finds `FC5` in the template. Extra characters such as dots or spaces do matter.

## How do I fix the names and look up the positions from the menus?

### 1. See the problem

1. Open the dataset `S001R03.set` you saved in [the import lesson](/en/lesson/import-raw/).
2. In the main window, the <UiLabel>Channel locations</UiLabel> line shows `No (labels only)`.
3. In the Command Window, type `{EEG.chanlocs(1:3).labels}`. The result is `'Fc5.'` `'Fc3.'` `'Fc1.'`: each name ends with a dot.

### 2. Remove the dots from the names

You can change one name by hand in <MenuPath>Edit > Channel locations</MenuPath>, in the <UiLabel>Channel label ("label")</UiLabel> field. But there are 64 names, so it is faster to remove the dots from all of them with four lines in the Command Window:

```matlab
for iChan = 1:EEG.nbchan
    EEG.chanlocs(iChan).labels = strrep(EEG.chanlocs(iChan).labels, '.', '');
end
[ALLEEG, EEG, CURRENTSET] = eeg_store(ALLEEG, EEG, CURRENTSET); eeglab redraw;
```

Type `{EEG.chanlocs(1:3).labels}` again. The result is now `'Fc5'` `'Fc3'` `'Fc1'`.

### 3. Look up the positions

1. Open <MenuPath>Edit > Channel locations</MenuPath>.
2. Because the channels have no positions yet, EEGLAB first opens a window titled <UiLabel>Look up channel locations?</UiLabel>.
3. Keep the default choice in the list: <UiLabel>use MNI coordinate file for BEM dipfit model</UiLabel>. The file under it is `standard_1005.elc`.
4. Leave <UiLabel>Import file instead and erase all channels</UiLabel> unticked.
5. Click <UiLabel>OK</UiLabel>. The Command Window prints `64 channel with the same label found and imported`.
6. The channel editing window opens, showing each channel with its coordinates. Click <UiLabel>OK</UiLabel> at the bottom to close it. The changes take effect only after you close this window.

### 4. Save

Open <MenuPath>File > Resave current dataset(s)</MenuPath>. This writes the fixed names and the positions into the same file `S001R03.set` in your lessons folder. Keep it: [the events lesson](/en/lesson/events/) continues on it.

## How do I do it all with a script?

```matlab
% Start EEGLAB and load the file from the previous lesson
[ALLEEG, EEG, CURRENTSET, ALLCOM] = eeglab;
dataFolder = 'C:\Users\me\Documents\eeg-course';   % change it
EEG = pop_loadset('filename', 'S001R03.set', 'filepath', dataFolder);
[ALLEEG, EEG, CURRENTSET] = eeg_store(ALLEEG, EEG, 0);

% Remove the trailing dots from the names (Fc5. -> Fc5, Cz.. -> Cz)
for iChan = 1:EEG.nbchan
    EEG.chanlocs(iChan).labels = strrep(EEG.chanlocs(iChan).labels, '.', '');
end

% Look up the positions in the standard MNI template
% (case does not matter: Fc5 matches FC5)
EEG = pop_chanedit(EEG, 'lookup', 'standard_1005.elc');
EEG = eeg_checkset(EEG);

% Plot the electrodes by name (same as Plot > Channel locations > By name)
figure; topoplot([], EEG.chanlocs, 'style', 'blank', ...
    'electrodes', 'labelpoint', 'chaninfo', EEG.chaninfo);

% Save over the lesson file and show the result in the main window
EEG = pop_saveset(EEG, 'savemode', 'resave');
[ALLEEG, EEG, CURRENTSET] = eeg_store(ALLEEG, EEG, CURRENTSET);
eeglab redraw
```

- `strrep(text, '.', '')` replaces every dot in the text with nothing.
- `'lookup', 'standard_1005.elc'` is the same as the default choice in the lookup window. EEGLAB finds this file inside the dipfit plugin that comes with EEGLAB.

## Where do I get positions if my cap is not standard?

| Source | When to use it | How |
|---|---|---|
| Standard MNI template (`standard_1005.elc`) | Your cap uses standard 10-20 or 10-10 names, and you did not measure the positions. This is our case. | The default choice in <UiLabel>Look up channel locations?</UiLabel> |
| Your cap's own location file (from the manufacturer) | Your system's channel names are not standard, such as the numbered names `E1`, `E2` | <UiLabel>Read locations</UiLabel> in the channel editing window |
| Positions measured on the participant's head | You digitized the electrodes at the recording session | <UiLabel>Read locations</UiLabel> with the digitizer's file |

## How do I verify that every channel has a position?

1. The <UiLabel>Channel locations</UiLabel> line in the main window shows `Yes`.
2. The Command Window printed `64 channel with the same label found and imported`.
3. Open <MenuPath>Plot > Channel locations > By name</MenuPath>. A head seen from above appears, nose at the top, with 64 electrodes each named in its place: `Cz` in the center, `Fpz` at the front, `Oz` at the back.
4. `all(~cellfun(@isempty, {EEG.chanlocs.X}))` gives `1`: every channel has coordinates.

## Why does the line still say No (labels only)? Common mistakes with channel locations

- **Looking up before removing the dots.** No name matches, and no warning appears. The <UiLabel>Channel locations</UiLabel> line stays `No (labels only)`. Remove the dots, then look up again.
- **Not closing the channel editing window with OK.** The changes take effect only after you close it.
- **Thinking the electrodes outside the circle are a mistake.** The circle marks the horizontal plane through the center of the head. Electrodes below that plane, around the lower edge of the cap (such as `T7`, `T8`, `T9`, `T10` and `Iz`), are drawn on or outside it. This is expected.
- **Ticking <UiLabel>Import file instead and erase all channels</UiLabel>.** This replaces your channels with all the template's channels (hundreds of names). Leave it unticked.
- **Assuming the file order follows the head.** In `S001R03.edf` the first channel is `Fc5`, not `Fp1`. Always look a channel up by its name, not by its number.
