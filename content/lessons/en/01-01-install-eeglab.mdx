## The idea

EEGLAB is a collection of functions written in MATLAB. So you need MATLAB first, then the EEGLAB folder itself.

Once it is installed, you extend EEGLAB with plugins. A plugin is a small package that adds menus and functions, for example to read a file format EEGLAB cannot read on its own.

Every later lesson assumes that EEGLAB runs on your computer and that the Biosig plugin is installed, so you can import EDF files in the [import lesson](/en/lesson/import-raw/). So how do you install it cleanly, once?

## What do I see when EEGLAB runs for the first time?

This is where the steps end: you type one command in MATLAB, and the EEGLAB window opens with its seven menus.

## Where do I get MATLAB?

The options are listed from best to weakest for these lessons.

| Option | Cost | Enough for these lessons? | Why |
|---|---|---|---|
| **University license** | Usually free for students | Yes, fully | Most universities provide a MATLAB license for their students. Ask your university IT department. The official documentation recommends the MATLAB version first. |
| **MATLAB Online (basic)** | Free with a MathWorks account | For trying things out, with limits | 20 hours per month, 5 GB of MATLAB Drive storage, and a 15-minute limit on continuous compute time (MathWorks page). In principle you can upload the EEGLAB folder to MATLAB Drive and type `eeglab`, but we have not tested this on 2026.1 yet. |
| **Compiled EEGLAB** | Free, no MATLAB | Mostly, but no new plugins | A ready-made version for Windows and macOS that does not need MATLAB. It ships with many plugins and runs simple scripts. But it has no <UiLabel>Manage EEGLAB extensions</UiLabel> menu, so you cannot add a new plugin to it. The documentation ranks it second after MATLAB. |
| **GNU Octave** | Free and open source | Partly | An open alternative to MATLAB. The official documentation says it is less stable than MATLAB and ranks it as the third and last choice. We do not promise that every lesson works on it. |

**MATLAB release:** the EEGLAB team recommends a recent, though not necessarily the newest, MATLAB release. If you have MATLAB 2016a or older, the download page points you to EEGLAB 2020.0, which this site does not cover.

## How do I install EEGLAB and the Biosig plugin from the GUI?

### 1. Download EEGLAB

1. Open the official download page: [Download EEGLAB](https://eeglab.org/others/How_to_download_EEGLAB.html).
2. Fill in the form: name and email, tick the box to accept the BSD license, then click <UiLabel>Submit</UiLabel>.
3. You get a ZIP file of the latest stable release.

<Callout type="warning">
Do not download the ZIP file from the EEGLAB page on GitHub. That file is missing essential plugins, as the official documentation warns.
</Callout>

### 2. Unzip it in a permanent place

Unzip the file in a folder you will not move later, such as `Documents/MATLAB`. You get a folder whose name starts with `eeglab` followed by the version number.

### 3. Save the path before the first run

Save the path **before** you type `eeglab`. The reason: when it starts, EEGLAB adds its subfolders to the path, and the save button saves the whole path as it is at that moment.

1. Open MATLAB, and do not start EEGLAB yet. If you already started it in this session, close MATLAB and open it again.
2. Type `pathtool` in the Command Window (or open <UiLabel>Set Path</UiLabel> from the MATLAB interface).
3. Click <UiLabel>Add Folder</UiLabel> and select the main EEGLAB folder only.
4. Click <UiLabel>Save</UiLabel>, then <UiLabel>Close</UiLabel>.

### 4. Start EEGLAB

Type `eeglab` in the Command Window and press <kbd>Enter</kbd>.

The EEGLAB main window opens with seven menus: <UiLabel>File</UiLabel>, <UiLabel>Edit</UiLabel>, <UiLabel>Tools</UiLabel>, <UiLabel>Plot</UiLabel>, <UiLabel>Study</UiLabel>, <UiLabel>Datasets</UiLabel> and <UiLabel>Help</UiLabel>. When it starts, EEGLAB adds its own subfolders to the path of the current session, without saving them.

From now on, typing `eeglab` in any new MATLAB session is enough.

### 5. Install the Biosig plugin

1. In the EEGLAB window, open <MenuPath>File > Manage EEGLAB extensions</MenuPath>. This needs an internet connection.
2. The list of plugins appears. Plugins in bold are installed on your computer, and red ones need an update.
3. Click the search button at the top of the window and type `Biosig`.
4. Select Biosig in the list, then click <UiLabel>Install/Update</UiLabel>.
5. EEGLAB downloads the plugin and rebuilds its window. Biosig reads EDF, BDF and many other formats.

The extension manager shows each plugin's star rating and download count, and sorts the list by downloads. When two plugins do the same job, these two numbers are a quick first guide. For what each common plugin does and when you need it, see the [Plugins guide](/en/plugins/).

### Should I update EEGLAB?

In the MATLAB version you will find <MenuPath>Help > Check for EEGLAB update</MenuPath>, and EEGLAB prints at startup whether you have the latest release. But these lessons are written for EEGLAB 2026.1, so do not update in the middle of the course. Menu names and numbers may change in a newer release.

## How do I do all of this with one script?

These are the same steps from the command line. Run the script once after unzipping EEGLAB, in a new MATLAB session where you have not started EEGLAB yet.

```matlab
% Go to the EEGLAB folder (change the path to yours)
cd('C:\Users\me\Documents\MATLAB\eeglab2026.1');

% Save the root EEGLAB folder in the path BEFORE starting EEGLAB,
% so its subfolders are not saved too
addpath(pwd);
savepath;

% Start EEGLAB; it adds its own subfolders for this session only
eeglab;

% Install Biosig only if it is not installed yet (needs internet)
if ~exist('sopen', 'file')
    plugin_askinstall('Biosig', 'sopen', true);
end
```

- `addpath(pwd)` then `savepath` save the main folder only, because they come before `eeglab`. If they came after it, `savepath` would save all the subfolders EEGLAB added, which is what the documentation warns against.
- `sopen` is a Biosig function. If it exists, the plugin is installed and there is no need to install it again.
- The third argument, `true`, installs the plugin without a confirmation dialog, so it works inside a script.

## How do I check the installation worked?

1. **The window:** the EEGLAB main window opened with its seven menus.
2. **The path:** close MATLAB, open it again, and type `which eeglab`. It should print the path of `eeglab.m` inside your folder. Also, when you run `eeglab`, no red warning about subfolders should appear.
3. **The version:** type `eeg_getversion`. It should print a version number starting with `2026.1`.
4. **The plugin:** type `exist('sopen', 'file')`. A result of `2` means Biosig is installed. Its name also appears in bold in the extension manager.
5. **Startup lines:** each time EEGLAB starts, it prints in the Command Window one line for each plugin it loads, starting with `EEGLAB: adding` followed by the plugin name and version. Look for Biosig.

## Which mistakes break the installation?

- **Downloading the ZIP from GitHub instead of the download page.** You miss essential plugins such as ICLabel, clean_rawdata and firfilt. Red warnings appear at startup for the first two, and EEGLAB asks to download firfilt the first time you filter.
- **Saving the folder with all its subfolders.** This happens with the <UiLabel>Add with Subfolders</UiLabel> button, or by saving the path after running `eeglab` in the same session. The documentation advises saving the main folder only, and EEGLAB prints a red warning at startup if it finds its subfolders saved.
- **Keeping an old EEGLAB release in the path.** If you install a new release, remove the old one in <UiLabel>Set Path</UiLabel> with the <UiLabel>Remove</UiLabel> button. Otherwise, MATLAB may call outdated functions.
- **Looking for the extension manager in the compiled version.** The menu does not exist there at all. If you need a plugin it does not include, you need the MATLAB version.
- **`savepath` or the <UiLabel>Save</UiLabel> button fails.** This usually happens when your account cannot write to the MATLAB folder. Run MATLAB as administrator once, or create a file named `startup.m` in the folder printed by the `userpath` command, and write one line in it: `addpath` followed by the EEGLAB folder path in parentheses. MATLAB runs this file automatically at the start of every session, and it needs no special permissions.
